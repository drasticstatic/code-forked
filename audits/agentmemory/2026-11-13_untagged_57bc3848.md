## Thank you

agentmemory is the work of its author and contributors, shared under the Apache License 2.0. Thank you for building it
and publishing it. The code is careful in ways a reader can check: the engine download is refused unless its SHA-256 is
pinned in the source, the capture spool refuses plain HTTP to anything but loopback, and the default is zero-LLM with a
plain notice saying so. What follows describes the code at one revision so anyone can choose how to run it; it is not a
judgement of the authors.

## TL;DR

1. **The documented launch is `npx -y …@latest`, and `connect claude-code` writes an `npx -y @agentmemory/mcp` entry
   into `~/.claude.json`.** Neither names a version, so what runs is what npm serves that day (1.1). The repository has
   no lock file.
2. **Hooks are opt-in (`--with-hooks`) and capture tool input and output** after secret scrubbing, a tool deny list and
   an 8,000-character cap (2.1).
3. **Default is zero-LLM and keyless.** A key in the environment does not on its own turn on a cloud provider; a
   provider has to be named (2.3).
4. **The CLI's own runtime binds the engine, REST API and viewer to `127.0.0.1`.** The separate container recipe binds
   `0.0.0.0` (2.4).
5. **The engine binary is checked against SHA-256 values pinned in the source**, and refused without one (1.3).
6. **The agent runbook tells an installing agent to skip npx's prompt** and to add skills with `-y` (4).
7. **A clean read is not a guarantee** ([last section](#a-clean-read-is-not-a-guarantee)).

## 1. Install paths

### 1.1 Launch and `connect`

- **FACT** `INSTALL_FOR_AGENTS.md:22, 53`: the canonical command is `npx -y @agentmemory/agentmemory@latest`.
- **FACT** `src/cli/connect/util.ts:13-21`: the MCP entry is `npx -y @agentmemory/mcp` (on Windows through `cmd /c`),
  with `AGENTMEMORY_URL` defaulting to `http://localhost:3111`.
- **FACT** `src/cli/connect/claude-code.ts:31, 122-133`: `connect claude-code` backs up `~/.claude.json` (or the file in
  `CLAUDE_CONFIG_DIR`) and writes `mcpServers.agentmemory`.
- **FACT** `claude-code.ts:104-105, 173-200`: hook entries are merged into `~/.claude/settings.json` only with
  `--with-hooks`; they reference absolute paths in the installed package.
- **INFERENCE:** pinning this repository's commit does not pin either npm package.

### 1.2 Dependencies

- **FACT** `package.json:84, 95`: `"license": "Apache-2.0"`, `"iii-sdk": "0.25.1"`.
- **FACT:** the tree at `57bc3848` (1,260 entries) has no `package-lock.json`, `pnpm-lock.yaml`, `yarn.lock` or
  `bun.lock`. The first reviewer had found no root lock and had not searched for nested ones.

### 1.3 Engine download (`src/cli/engine-install.ts`)

- **FACT** `engine-install.ts:17-29`: `III_RELEASE_SHA256` pins the SHA-256 of each `iii` release archive per platform

  `:145-149`: a mismatch deletes the archive and refuses.
- **FACT** `INSTALL_FOR_AGENTS.md:9`: the engine goes to `~/.agentmemory/bin`.

## 2. Data

### 2.1 Hooks

- **FACT** `plugin/hooks/hooks.json`: entries for SessionStart, UserPromptSubmit, PreToolUse
  (`Edit|Write|Read|Glob|Grep`), PostToolUse, PostToolUseFailure, PreCompact, SubagentStart, SubagentStop,
  Notification, TaskCompleted, Stop and SessionEnd.
- **FACT** `plugin/scripts/post-tool-use.mjs:30-56`: secret patterns, private-key blocks and URL credentials are
  replaced with `[REDACTED_SECRET]`. `:86-91`: tools denied by default: `memory_*`, `toolsearch`, `listmcpresources`,

  8,000 characters unless `AGENTMEMORY_CAPTURE_OUTPUT_MAX` is set.

### 2.2 Spool and transport (`plugin/scripts/_capture.mjs`)

- **FACT** `:375, 377, 407`: spool on by default, 5 MiB, 168 hours; `AGENTMEMORY_CAPTURE_SPOOL=false` turns it off.
- **FACT** `:450-461`: directory mode 0700, files 0600.
- **FACT** `:120, 140`: *"AGENTMEMORY_URL must use HTTPS unless it is a loopback address. Nothing was sent."*
- **FACT** `:85-91`: the stored client secret is attached only for loopback URLs; for another host it must come from the
  environment.

### 2.3 Providers (`src/config.ts`)

- **FACT** `:184-186`: an LLM provider is selected only by `AGENTMEMORY_LLM_PROVIDER`. `:236-240`: a named provider
  without its key falls back to noop. `:272-285`: with none named, *"agentmemory runs zero-LLM … no session content
  leaves this machine for an LLM."*
- **FACT** `:228`: *"cloud embeddings stay off until you choose them"*, even when a key is present.
- **FACT** `:115-125, 343-348`: `~/.agentmemory/.env` is loaded into the process environment, and the process
  environment wins over it.
- **FACT** `:287-297`: `AGENTMEMORY_ALLOW_AGENT_SDK=true` uses Claude Agent SDK child sessions instead.
- **Where the readings differ:** the first reviewer wrote that existing keys or config may select remote processing.
  The second reviewer reads config as able to, and keys alone as not.

### 2.4 Listeners

- **FACT** `src/config.ts:305-314`: REST 3111, viewer REST+2 (3113), engine `ws://localhost:49134`.
- **FACT** `src/cli/compose-project.ts:299, 343-351`: the runtime file the CLI writes binds the engine manager and the
  REST worker to `127.0.0.1`, with loopback-only CORS.
- **FACT** `src/viewer/server.ts:74`: viewer default `127.0.0.1`; `:232-237`: a non-loopback viewer requires
  `AGENTMEMORY_SECRET` and `VIEWER_ALLOWED_HOSTS`.
- **FACT** `src/auth.ts:6-9, 16, 115-121`: timing-safe secret comparison, a nonce CSP for the viewer, an origin guard.
- **FACT** `deploy/runtime/worker-compose.yaml:45, 73`: the container recipe binds REST to `0.0.0.0` and the viewer to
  `${AGENTMEMORY_VIEWER_HOST:-0.0.0.0}`. **INFERENCE:** inside a container that is normal; what is reachable then

### 2.5 Maintenance and storage

- **FACT** `src/config.ts:359-361, 376-382`: session sweep and graph compaction on boot are on unless set to `"false"`;
