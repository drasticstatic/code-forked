## TL;DR

A library of skills (Markdown instructions). **No hooks, no settings writes, no permission flags.**

1. **The plugin routes update themselves; copied files do not.** One route installs with `npx skills@latest`, which
   is unpinned (1).
2. **The setup skill edits the repository it is run in**: `CLAUDE.md` or `AGENTS.md`, files under `docs/agents/`, and
   issue-tracker labels through the user's logged-in `gh` or `glab`. It shows drafts and asks before writing. Only the
   user can start it (2).
3. **A maintainer-only script deletes same-named skill folders** in `~/.claude/skills` and `~/.agents/skills` before
   linking its own. It is labelled as not an installer (3).
4. **MIT** (4).
