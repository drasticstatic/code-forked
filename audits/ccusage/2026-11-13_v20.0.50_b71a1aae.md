## TL;DR

At this revision ccusage is a native Rust program, started by a small Node launcher.

1. **The npm package is a launcher.** It finds a prebuilt binary in an optional platform package and runs it. It does
   not download anything itself, and the published package has no install scripts (1).
2. **It reads local agent logs**, such as Claude Code's session JSONL files, which hold conversation content. In the
   code read, nothing from them is sent anywhere (2).
3. **Reports fetch model prices by default**, from LiteLLM's file on GitHub and from models.dev, with tight limits and
   caching. Off: `--offline` or `--mode display`. The `statusline` command is offline by default (3).
4. **MIT** (4).

### 1. The npm launcher

- **FACT** `apps/ccusage/src/cli.js:30-61`: maps platform and architecture to one of six packages, such as
  `@ccusage/ccusage-darwin-arm64`. `:75-90` resolves its `bin/ccusage`. `:149` may set it to mode `0755`.
- **FACT** `:117-118`: when the package is missing it prints *"Missing optional native package … Reinstall ccusage with
  optional dependencies enabled and no release-age cutoff."* No network code appears in the file.
- **FACT** `apps/ccusage/package.json:20-23`: the published files are `config-schema.json` and `src/cli.js`. `:32-39`
  lists the six platform packages as `optionalDependencies`. There is no `install` or `postinstall` script. (The root
  `package.json`'s `preinstall` belongs to the private monorepo.)
- **INFERENCE:** what runs is a prebuilt binary from npm. Nothing in this repository shows that it was built from this
  source.

### 2. Reading local logs

- **FACT** `rust/adapters/claude/src/lib.rs:188-233`: finds the Claude data folders (`claude_paths`), lists the usage
  JSONL files, and reads them in parallel. `:220-228`: loads prices unless the mode is `Display`.
- **FACT:** the adapter has no HTTP client. The binary's only HTTP request is a GET (`rust/crates/ccusage/src/http.rs:89`)
  to one of two fixed pricing URLs (3), with no request body.

### 3. Pricing fetches

- **FACT** `rust/crates/ccusage-core/src/pricing.rs:97-99`:
  `https://raw.githubusercontent.com/BerriAI/litellm/main/model_prices_and_context_window.json` and
  `https://models.dev/api.json`. `http.rs:31-35` refuses any other URL.
- **FACT** `http.rs:16-17`: a 10-second timeout and a 64 MiB limit. `:27-29`: the response is cached with its ETag,
  and a cached body is used only after a 304 and the endpoint's validator.
- **FACT** `rust/crates/ccusage-cli/src/types.rs:262-264`: the default cost mode is `Auto`, which needs prices. Report
  options derive `Default`, so `offline` starts false; `-O` / `--offline` sets it
  (`ccusage-cli-parser/src/parser.rs:821`).
- **FACT** `types.rs:240-244`: the `statusline` command's defaults set `offline: true`.
- **Off:** `--offline` (embedded price snapshots are used), or `--mode display` (no prices loaded).
- **INFERENCE:** the hosts see a request from the machine at report time. The data sent is the GET itself; no usage
  data is attached.

### 4. Licence
