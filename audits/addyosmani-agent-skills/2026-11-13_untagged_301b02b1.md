## TL;DR

A library of skills, slash commands and agent personas. **The plugin registers no hooks.** The hooks in `hooks/` ship
as optional scripts for a user to wire in by hand.

1. **Nothing runs by default beyond commands and skills.** The manifests have no `hooks` key (1).
2. **The optional `simplify-ignore` hook edits real files on disk** while a session is active, and restores them at
   Stop (2).
3. **The optional `sdd-cache` hooks make network requests and can stand in for WebFetch**, serving a cached copy when
   the server answers 304 (3).
4. **One setup guide mentions `--dangerously-skip-permissions`** for trusted local projects, after offering a
   sandbox. It is advice, not a default (4).
5. **The quick-start installer is an unpinned `npx`** (5).

### 1. What the plugin wires

- **FACT** `.claude-plugin/plugin.json:11-12`: `"commands": ["./.claude/commands", "./commands"], "skills": "./skills"`.
  No `hooks` key there, nor in `plugin.json`, `.codex-plugin/plugin.json` or the marketplace files.
- **FACT** `hooks/session-start.sh:5-8`: *"Not wired by the plugin: hosts that already route skills from their
  descriptions (Claude Code, Codex CLI) would run a second router on top of the native one."*
- **FACT** `docs/antigravity-setup.md:112`: the repository's own `AGENTS.md` and `CLAUDE.md` are for contributors; *"Do
  not copy or link them into your project or global agent configuration"*.

### 2. `hooks/simplify-ignore.sh` (opt-in)

- **FACT** `:4`: *"PreToolUse Read → backs up file, replaces blocks with BLOCK_<hash> in-place"*. `:7-9`: Stop expands
  the placeholders back.
- **FACT** `:11`: *"The file on disk ALWAYS has placeholders while the session is active."*
- **FACT** `:31`: state is kept in the project at `.claude/.simplify-ignore-cache`. `:396-403`: a `mkdir` lock against
  concurrent sessions. `:358`: a `.recovered` path.
- **INFERENCE:** if a session ends without its Stop hook (a crash, a killed terminal), real source files keep their
  placeholders until recovered. Other tools that read the files in the meantime (an editor, a build, another agent)
  see the placeholders.

### 3. `hooks/sdd-cache-pre.sh` and `sdd-cache-post.sh` (opt-in)

- **FACT** `:50`: cache in the project at `.claude/sdd-cache`.
- **FACT** `:71-74`: `curl -sI … --max-time 5 -L` with `If-None-Match` / `If-Modified-Since` to the URL being fetched.
- **FACT** `:96-97`, `:106`: on a 304 it prints *"Use the cached content below as if WebFetch had just returned it."*
  and exits 2, which blocks the WebFetch.
- **What it means:** what the agent sees is a stored earlier answer. The 304 shows that the server's page is
  unchanged; it does not check the stored copy itself.

### 4. Permission advice

- **FACT** `docs/antigravity-setup.md:114-119`: *"Sandbox Mode … `agy --sandbox`"*. `:130`: *"You can use the

- **FACT:** the only permission flags in code are in the evaluation runner, `scripts/run-evals.js:649`
