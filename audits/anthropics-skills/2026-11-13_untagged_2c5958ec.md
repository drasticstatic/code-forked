## TL;DR

A library of skills (Markdown instructions plus helper scripts) that an agent loads when it needs them. Nothing runs
on install: there are **no hooks** and no settings writes. Scripts run only when a skill leads the agent to run them.

1. **The licence finding no longer holds at this revision.** The docx, pdf, pptx and xlsx skills are **Apache 2.0**
   here; this commit is the one that moved them. The restrictive terms described in the first read belong to the
   commit before it. There is still no root licence file, and one skill folder has none (3).
2. **The web-artifacts installer installs packages, one of them globally.** `npm install -g pnpm` if pnpm is missing,
   then many unpinned packages into the new project (1).
3. **The skill-creator evaluation runs `claude -p` many times on the user's own login**, and writes a temporary
   command file under `.claude/commands/`. No permission-bypass flag is used (2).

### 1. `web-artifacts-builder/scripts/init-artifact.sh`

- **FACT** `:34-36`: if `pnpm` is not on `PATH`, `npm install -g pnpm`. That is the only write outside the new
  project folder.
- **FACT** `:18-24`, `:59`, `:72-75`: `pnpm create vite "$PROJECT_NAME" --template react-ts` always uses the latest
  `create-vite`. A specific Vite (`5.4.11`) is pinned only when Node is older than 20; on Node 20 or newer the
  version is whatever the registry serves that day.
- **FACT** `:78-79`, `:272-273`: further installs without versions (Tailwind is pinned to `3.4.1`; Radix UI, sonner,
  cmdk, zod, date-fns and others are not). `:277` unpacks the bundled `shadcn-components.tar.gz` into `src/`.
- **FACT** `bundle-artifact.sh:21`: adds `parcel`, `@parcel/config-default`, `parcel-resolver-tspaths` and
  `html-inline`.
- **Default:** nothing runs until the agent or user runs the script. The packages installed depend on the registry on
  the day.

### 2. `skill-creator/scripts/run_eval.py`

- **FACT** `:53-68`: writes `.claude/commands/<skill>-skill-<random>.md` in the nearest folder upward that has a
  `.claude/` directory (`find_project_root`, `:22-32`), so possibly above the working directory. `:181` removes it
